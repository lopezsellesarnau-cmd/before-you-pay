# Sample data

`serpavi_sample.csv`: real rows of SERPAVI (Ministerio de Vivienda y Agenda Urbana,
dataset 2011-2024) for Madrid municipality and its census districts, 2023-2024, flats only.
Used only when Zetaris is not configured and the full prepared CSV is not on disk, so the
agent runs out of the box. Full data: `scripts/prepare_serpavi.py`.
